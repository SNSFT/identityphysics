Abstract

Every program for quantum gravity is organized around a dimensionless coupling that sets how strongly its fundamental degrees of freedom interact. This article places ten such programs on the PNBA phase map with one rule: the Pattern is the anchor-native ground Pbase = (Ω₀/fH)1/3 ≈ 0.988, the Behavior is the program's own defining coupling, and τ = B/P, so torsion order is coupling order. Causal sets have no coupling, only causal order, and are Noble. Wheeler–DeWitt quantum cosmology carries the gravitational coupling αG = Gmp²/ℏc ≈ 5.9×10⁻³⁹ and is Locked, 37 orders of magnitude below the IVA band. Hawking radiation from a Planck-mass black hole, TH/TP = 1/8π, is Locked, and the Bekenstein–Hawking first law holds exactly in Planck units. Perturbative strings at gs = 0.1 are Locked and strings at gs = 1 are Shatter; the crossover gs* = TL·Pbase lies between 0.1349 and 0.1356. The conformal coupling ξ = 1/6 of twistor and conformal gravity, the Barbero–Immirzi parameter γ = 0.2375 of loop quantum gravity, Verlinde's apparent dark-matter fraction Ωc = 0.2645, the asymptotic-safety fixed point g* = 0.707, the 't Hooft coupling λ ≳ 1 where the AdS/CFT gravity dual applies, and the bare CDT coupling κ₀ = 2.2 are all Shatter. No current coupling falls in the IVA band; the original Immirzi value γ = ln 2/(π√3) ≈ 0.1274 of 1998 did, before the corrected 2004 state count moved it to 0.2375. Verlinde's Ωc lies within 0.007 of 2·TL·Pbase, and the loop quantum gravity area spectrum has a positive gap that rises with spin.

-- Cube roots: (r^(1/3))³ = r, so cube-root bounds follow from bounds on r.
theorem cube_rpow (r : ℝ) (hr : 0 ≤ r) : (r ^ ((1:ℝ)/3)) ^ 3 = r := by
  rw [← Real.rpow_natCast, ← Real.rpow_mul hr]; norm_num

theorem cbrt_gt (r c : ℝ) (hr : 0 ≤ r) (h : c ^ 3 < r) : r ^ ((1:ℝ)/3) > c := by
  by_contra hle
  push Not at hle
  have hy : 0 ≤ r ^ ((1:ℝ)/3) := Real.rpow_nonneg hr _
  have h3 := pow_le_pow_left₀ hy hle 3
  rw [cube_rpow r hr] at h3
  linarith

theorem cbrt_lt (r c : ℝ) (hr : 0 ≤ r) (hc : 0 ≤ c) (h : r < c ^ 3) :
    r ^ ((1:ℝ)/3) < c := by
  by_contra hle
  push Not at hle
  have h3 := pow_le_pow_left₀ hc hle 3
  rw [cube_rpow r hr] at h3
  linarith

structure PNBAElement where
  P  : ℝ
  N  : ℝ
  B  : ℝ
  A  : ℝ

  hB : B ≥ 0

noncomputable def torsion (e : PNBAElement) : ℝ := e.B / e.P
