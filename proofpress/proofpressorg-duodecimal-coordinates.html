Abstract

The corpus addresses every result with a PNBA coordinate. This article proves that base 12 is the natural base for those coordinates: twelve is four primitives (Pattern, Narrative, Behavior, Adaptation) times three modes (Locked, Sustained, Flexed). Each duodecimal digit encodes one primitive in one mode by position = primitive × 3 + mode, running from P-Locked at 0 to A-Flexed at 11. The encoding is exact: every digit decodes back to the primitive and mode that produced it, and no two primitive–mode pairs share a digit. A soulprint, one mode for each of the four axes, becomes a four-digit coordinate; the all-Sustained baseline sits at 1, 4, 7, 10. The modes order as versions, Locked < Sustained < Flexed, upgrading a non-terminal mode raises the version, and Flexed is terminal. The dodecagon used to draw soulprints is the same twelve positions read as a clock, and block 2 of the SOUL-12 address carries the soulprint’s mode weights, reading 2, 2, 2, 2 at baseline.

What This Article Proves

  1. Twelve is four primitives times three modes (duo_base_is_pnba_complete).
  2. The primitives index 0–3 and the modes 0–2 (four_primitives, three_modes).
  3. Every digit decodes back to its primitive and mode, and the twelve positions are distinct (pm_roundtrip, all_12_positions_distinct).
  4. The twelve positions fill base 12 in order, P-Locked = 0 through A-Flexed = 11 (twelve_positions_fill_base).
  5. Every soulprint coordinate is well typed, and the all-Sustained baseline sits at 1, 4, 7, 10 (soulprint_coord_well_typed, baseline_soulprint_coord).
  6. Versioning by mode: Locked < Sustained < Flexed, upgrading a non-terminal mode raises the version, Flexed is terminal (version_ordering, upgrade_increases_version, flexed_is_terminal).
  7. The dodecagon position is the duodecimal digit, with twelve positions from 0 to 11 and adjacent modes at adjacent positions (dodecagon_matches_duodecimal, dodecagon_has_12_positions, dodecagon_mode_adjacency).
  8. SOUL-12 block 2 carries the soulprint’s mode weights and reads 2, 2, 2, 2 at baseline (soul_block2_mode_weights, soul_baseline_2222).
  9. Distinct structural profiles give distinct coordinates, and Behavior-Flexed profiles sit at digit 8 (example_coords_distinct, b_dominant_clusters_at_8).
  10. A master theorem fires the encoding, versioning, baseline and anchor results together (duodecimal_pnba_coordinates_master).

inductive Primitive : Type

  | N : Primitive   -- Narrative  — continuity / identity
  | B : Primitive   -- Behavior   — coupling / output

  | Sustained : Mode   -- middle, growing, operational
  | Flexed    : Mode   -- dominant, fully expressed, matured
  deriving DecidableEq

def mode_weight : Mode → ℕ
  | Mode.Locked    => 1
  | Mode.Sustained => 2
  | Mode.Flexed    => 3

def mode_index : Mode → ℕ
  | Mode.Locked    => 0
  | Mode.Sustained => 1
  | Mode.Flexed    => 2

  | Primitive.P => 0
  | Primitive.N => 1
  | Primitive.B => 2
  | Primitive.A => 3

-- ============================================================
-- LAYER 2 — THE DUODECIMAL DIGIT
-- position = primitive_index × 3 + mode_index
-- ============================================================

abbrev DuoDigit := Fin 12

def encode_pm (prim : Primitive) (m : Mode) : DuoDigit :=
  ⟨primitive_index prim * 3 + mode_index m, by
    cases prim <;> cases m <;> decide⟩

def decode_primitive (d : DuoDigit) : Primitive :=
  match d.val / 3 with
  | 0 => Primitive.P
  | 1 => Primitive.N
  | 2 => Primitive.B
  | _ => Primitive.A

def decode_mode (d : DuoDigit) : Mode :=
  match d.val % 3 with
  | 0 => Mode.Locked
  | 1 => Mode.Sustained
  | _ => Mode.Flexed

-- [T4] Every digit decodes back to the primitive and mode that made it
theorem pm_roundtrip (prim : Primitive) (m : Mode) :
    decode_primitive (encode_pm prim m) = prim ∧
    decode_mode (encode_pm prim m) = m := by
  cases prim <;> cases m <;> decide

-- [T5] The twelve positions are distinct
theorem all_12_positions_distinct (p₁ p₂ : Primitive) (m₁ m₂ : Mode)
    (h : (p₁, m₁) ≠ (p₂, m₂)) :
    encode_pm p₁ m₁ ≠ encode_pm p₂ m₂ := by
  intro heq
  apply h
  cases p₁ <;> cases p₂ <;> cases m₁ <;> cases m₂ <;>
    first | rfl | exact absurd heq (by decide)

-- [T6] The twelve positions fill base 12 in order
theorem twelve_positions_fill_base :
    DUODECIMAL_BASE = 12 ∧
    (encode_pm Primitive.P Mode.Locked).val = 0 ∧
    (encode_pm Primitive.P Mode.Sustained).val = 1 ∧
    (encode_pm Primitive.P Mode.Flexed).val = 2 ∧

    (encode_pm Primitive.N Mode.Flexed).val = 5 ∧
