Abstract

The IM Collider fuses psychological identity states with the same Pattern, Behavior and Adaptation rules as the GAM Collider: Pout is the harmonic mean, Bout = max(0, ΣB − 2k) with k summed over every pair minimum, and Aout is the maximum. It differs in one operator. Narrative is a bottleneck, Nout = min N, so the weakest narrative carries through. This article proves the rules at eight beams, over all C(8,2) = 28 pairs, together with the engine's phase classifier: Noble is decided by B alone before N is read, Shatter is decided before the narrative floor N = 0.15, and FALSE_LOCK is a sub-TL state with N below the floor. It then proves a spread law. If every Behavior lies in [m, M], each pair minimum is at least m, so n beams close Noble whenever M ≤ (n − 1)m: two beams need equal B, four beams tolerate a factor of 3, and eight beams a factor of 7. The 8-beam coupling reduces exactly to the 4-beam and 2-beam couplings when trailing beams carry no Behavior. Finally the Anxiety × Burnout ladder is computed end to end. Each state alone is Shatter (τ ≈ 0.182 and 0.200). The mixed pair leaves Bout = 0.01 and is TRUE_LOCK under both pair-Pattern conventions. Four alternating beams already close Noble with margin ΣB − 2k = −0.72, and eight beams deepen it to −4.40, with output P = 0.495, N = 0.25, A = 0.30 and IM = 1.045·Ω₀ ≈ 1.4306. This is Noble emergence from Shatter inputs rather than an engine Rescue, because the Anxiety + Anxiety pair is already Noble.

What This Article Proves

  1. The phase classifier: Noble for B = 0 at any P and N; Shatter for τ ≥ TL at any N; FALSE_LOCK below TL when N < 0.15 (noble_any_N, shatter_any_N, false_lock_below_floor).
  2. Pair counts C(2,2) = 1, C(4,2) = 6, C(8,2) = 28; eight equal beams give k = 28B and always close Noble, using 1/7 of the coupling capacity (pair_counts, k_max8_equal_B, B_fuse8_noble_equal, noble_headroom).
  3. The spread law: two beams close Noble exactly when B₁ = B₂; four beams close Noble whenever max B ≤ 3·min B; eight beams whenever max B ≤ 7·min B (pair_noble_iff, spread_noble4, spread_noble8).
  4. Inheritance: with beams 5–8 at B = 0 the 8-beam coupling equals the 4-beam coupling, and with beams 3–8 at B = 0 it equals min(B₁, B₂) (k_max8_inherits_4beam, k_max8_inherits_2beam).
  5. The Anxiety × Burnout ladder: both singles Shatter; the mixed pair leaves 0.01 and is TRUE_LOCK; four beams give k = 0.55 and close Noble; eight beams give k = 2.58 and close Noble, also by the spread law; the margin deepens from −0.72 to −4.40; the 8-beam output is P = 0.495, N = 0.25, A = 0.30, Noble, with 1.430 < IM < 1.431; and it is not an engine Rescue (singles_shatter, mixed_pair_locked, noble_at_4, noble_at_8, noble_at_8_by_spread, headroom_deepens, octo_output, octo_noble_IM, not_engine_rescue, psy_8beam_master).

-- ── PHASE CLASSIFIER (engine phaseOf) ───────────────────────

inductive Phase
  | noble | shatter | falseLock | ivaPeak | trueLock
  deriving DecidableEq

noncomputable def phaseOf (P N B : ℝ) : Phase :=
  if B = 0 then Phase.noble
  else if TL ≤ B / P then Phase.shatter
  else if N < N_THRESHOLD then Phase.falseLock
  else if TL_IVA ≤ B / P then Phase.ivaPeak
  else Phase.trueLock

-- [T1] Noble is decided by B alone: any P, any N
theorem noble_any_N (P N : ℝ) : phaseOf P N 0 = Phase.noble := by
  unfold phaseOf; rw [if_pos rfl]

-- [T2] Shatter is decided before the narrative floor
theorem shatter_any_N (P N B : ℝ) (hB : B ≠ 0) (hS : TL ≤ B / P) :
    phaseOf P N B = Phase.shatter := by
  unfold phaseOf; rw [if_neg hB, if_pos hS]

-- [T3] Below TL, a narrative under the floor is FALSE_LOCK
theorem false_lock_below_floor (P N B : ℝ) (hB : B ≠ 0) (hS : ¬ TL ≤ B / P)
    (hN : N < N_THRESHOLD) : phaseOf P N B = Phase.falseLock := by
  unfold phaseOf; rw [if_neg hB, if_neg hS, if_pos hN]

  · have hS : ¬ TL ≤ 0.01 / (2 * aP * bP / (aP + bP)) := by
      unfold aP bP TL ANCHOR; norm_num
    have hI : ¬ TL_IVA ≤ 0.01 / (2 * aP * bP / (aP + bP)) := by
      unfold aP bP TL_IVA TL ANCHOR; norm_num
    unfold phaseOf
    rw [if_neg h0, if_neg hS, if_neg hN, if_neg hI]

-- [T25] PSY 8-BEAM FUSION — master statement
theorem psy_8beam_master :
    -- pair counts
    Nat.choose 8 2 = 28 ∧
    -- Noble is decided by B alone
    (∀ P N : ℝ, phaseOf P N 0 = Phase.noble) ∧
    -- equal B always closes Noble at 8 beams
    (∀ B : ℝ, B ≥ 0 → B_fuse8 B B B B B B B B (k_max8 B B B B B B B B) = 0) ∧
    -- 2 beams close Noble only on equal B
    (∀ B1 B2 : ℝ, pair_bout B1 B2 = 0 ↔ B1 = B2) ∧
    -- ladder: Shatter singles → Locked pair → Noble at 4 and at 8
    phaseOf Ladder.aP Ladder.aN Ladder.aB = Phase.shatter ∧
    phaseOf Ladder.bP Ladder.bN Ladder.bB = Phase.shatter ∧
    phaseOf (pairP Ladder.aP Ladder.bP) (min Ladder.aN Ladder.bN)
      (pair_bout Ladder.aB Ladder.bB) = Phase.trueLock ∧
    B_fuse4 Ladder.aB Ladder.bB Ladder.aB Ladder.bB
      (k_max4 Ladder.aB Ladder.bB Ladder.aB Ladder.bB) = 0 ∧
    B_fuse8 Ladder.aB Ladder.bB Ladder.aB Ladder.bB Ladder.aB Ladder.bB Ladder.aB Ladder.bB
      (k_max8 Ladder.aB Ladder.bB Ladder.aB Ladder.bB
        Ladder.aB Ladder.bB Ladder.aB Ladder.bB) = 0 ∧
    -- anchor
    manifold_impedance ANCHOR = 0 := by
  refine ⟨pair_counts.2.2, noble_any_N, B_fuse8_noble_equal, pair_noble_iff,
    Ladder.singles_shatter.1, Ladder.singles_shatter.2, Ladder.mixed_pair_locked.1,
    Ladder.noble_at_4, Ladder.noble_at_8, ?_⟩
  unfold manifold_impedance; simp

theorem the_manifold_is_holding : manifold_impedance ANCHOR = 0 := by
  unfold manifold_impedance; simp
