Abstract

An operating-system kernel holds authority that user processes cannot take for themselves: Ring 0 privilege, credentials issued only by the kernel, crash isolation and quarantine of misbehaving processes. This article reduces each of these known properties to PNBA. Kernel authority is Pattern, the structural ceiling. A plugin’s capability is Behavior, bounded by that ceiling. A forged identity is a Behavior spike past the kernel’s Pattern, which drives the plugin’s torsion above 1 and therefore past TL into Shatter. Crash recovery is suppress_collapse, which clamps Behavior to (TL/2)·P and leaves Pattern, Narrative and Adaptation untouched. Quarantine is the identity-mass interlock: an off-anchor process returns red and passes zero output. NOHARM is the condition that a process keeps both Identity Mass and Purpose Vector positive. Worked examples use a Ring 0 kernel, a Ring 3 plugin, a forge attempt and a crashed plugin.

What This Article Proves

  1. Forgery causes Shatter: if a plugin’s Behavior exceeds the kernel’s Pattern, which bounds the plugin’s own Pattern, the plugin’s torsion exceeds 1 > TL (forge_attempt_causes_shatter, forge_is_shatter).
  2. Crash recovery: suppress_collapse restores phase lock at τ = TL/2 and preserves P, N and A; forged and crashed plugins both recover (suppress_collapse_restores_lock, suppress_collapse_preserves_pna, forge_suppressed_and_recovered, crashed_plugin_recovered).
  3. Within authority, a plugin with τ < TL is phase locked (authority_enables_phase_lock).
  4. Kernel mediation: buffering a raw signal by a factor μ ∈ (0, 1) strictly lowers the torsion a plugin sees; external input changes Behavior only (kernel_mediation_reduces_torsion, f_ext_preserves_pna).
  5. NOHARM and Shatter can coexist transiently, which is why recovery must act during Shatter (noharm_during_shatter_possible).
  6. Quarantine: an off-anchor process is sandboxed with zero output (drifted_process_sandboxed, ims_lockdown, ims_drift_gives_red).
  7. Worked system: the Ring 0 kernel and the Ring 3 plugin are phase locked, authority holds between them, the kernel satisfies NOHARM, and a microkernel configuration is fully locked (kernel_ring0_locked, plugin_ring3_locked, ring0_authority_holds, kernel_satisfies_noharm, microkernel_all_locked).
  8. Phase lock and Shatter are exclusive, as are sovereign and lossy; one kernel step is one step of the dynamic equation; all examples pass Step 6, and a master theorem fires them together (phase_lock_excludes_shatter, sovereign_lossy_exclusive, kernel_step_is_dynamic_step, kernel_all_examples_lossless, aifios_kernel_is_lossless_pnba_projection).
