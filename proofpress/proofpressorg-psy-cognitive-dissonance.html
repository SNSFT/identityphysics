Abstract

Festinger’s theory holds that acting against one’s own belief creates dissonance, an uncomfortable tension that motivates resolution. In the classic Festinger and Carlsmith (1959) study, people paid $1 to describe a boring task as interesting later rated it more enjoyable, while those paid $20 did not, because the larger payment justified the act. This article reduces dissonance to PNBA. Belief is Pattern, the story linking belief to behavior is Narrative, the contradictory act is Behavior, and the resolution mechanism is Adaptation. External justification enters as Fext, absorbing part of the Behavior load. Consonance is a true lock. High dissonance ($1) is Shatter phase at τ = 0.367. Low dissonance ($20) stays locked at τ = 0.125. Attitude change is a genuine re-lock driven by Adaptation above 1. Denial lowers torsion by shutting Narrative down below threshold. That makes it a false lock, the same structural event as avoidant attachment. This is the first cross-domain instance of the false lock in the corpus.

What This Article Proves

  1. A false lock is never a true lock; in particular denial is not genuine resolution (false_lock_not_true_lock, denial_is_false_not_true, phase_lock_excludes_shatter).
  2. External justification: removing part of the Behavior load through an external reason strictly lowers torsion, the structural form of the $20 condition (external_justification_reduces_torsion, f_ext_preserves_pna).
  3. Consonance (P 1.0, N 1.0, B 0.08, A 0.8): τ = 0.08, true lock (consonance_is_true_lock).
  4. High dissonance, $1 condition (P 0.6, N 0.4, B 0.22, A 0.9): τ = 0.367, Shatter (high_dissonance_is_shatter).
  5. Low dissonance, $20 condition (P 0.8, N 0.85, B 0.10, A 0.5): τ = 0.125, phase locked and a true lock (low_dissonance_is_phase_locked, low_dissonance_is_true_lock).
  6. Attitude change (P 0.9, N 0.85, B 0.10, A 1.1): τ = 0.111, true lock, with IVA dominance (attitude_change_is_true_lock, attitude_change_iva_dominance).
  7. Denial (P 0.75, N 0.10, B 0.08, A 0.4): τ = 0.107, a false lock that is neither true lock nor Shatter (denial_is_false_lock, denial_not_true_lock, denial_not_shatter).
  8. One dissonance step is one step of the dynamic equation; all examples pass Step 6, and a master theorem fires them with the interlock (dissonance_step_is_dynamic_step, sovereign_lossy_exclusive, dissonance_all_examples_lossless, dissonance_is_lossless_pnba_projection).
