Abstract

Chemistry fixes the ratio of atoms in a binary compound by balancing valence or charge. This article derives that ratio from PNBA. Each element carries a Behavior value B, its bond valence. Treat each side of a formula unit as one beam carrying its total Behavior, n₁·B₁ and n₂·B₂. Under the GAM Collider rules the two-beam residual is |n₁·B₁ − n₂·B₂|, so the formula unit closes Noble, Bout = 0, exactly when n₁·B₁ = n₂·B₂. This is the B-balance stoichiometry law, and its smallest solution is n₁ = B₂/gcd(B₁, B₂), n₂ = B₁/gcd(B₁, B₂), proved for all positive B. Ten known compounds are recovered: gallium nitride, silicon carbide, alumina (2:3), zinc oxide, sodium chloride, gallium arsenide, nickel oxide, titanium carbide, magnesium oxide and silver chloride, together with molybdenum trisulfide (1:3), the case where gcd(B₁, B₂) > 1. For each, the production recipe massi = ni × MWi is computed exactly from IUPAC 2021 atomic weights, with no free parameters. The same law predicts arsenic nitride, AsN, at 1:1 (74.922 g arsenic and 14.007 g nitrogen per formula unit), a compound with no stable bulk phase reported in the literature.

What This Article Proves

  1. The GCD-reduced ratio satisfies B-balance for all positive B: (B₂/g)·B₁ = (B₁/g)·B₂ with g = gcd(B₁, B₂) (b_balance_law).
  2. The two-sided residual is |n₁B₁ − n₂B₂|, so a formula unit is Noble exactly when n₁B₁ = n₂B₂, and every B-balanced unit closes Noble (side_residual_abs, noble_iff_b_balance, balanced_unit_noble).
  3. B-balance for GaN, SiC, Al₂O₃, ZnO, NaCl, GaAs, NiO, TiC, MgO, AgCl, MoS₃ and the AsN prediction (GaN_b_balance … AsN_b_balance).
  4. Exact recipes per formula unit from IUPAC 2021 weights, e.g. GaN 69.723 + 14.007 = 83.730 g, Al₂O₃ 53.964 + 47.997 = 101.961 g, MoS₃ 95.950 + 96.195 = 192.145 g, AsN 74.922 + 14.007 = 88.929 g (GaN_mass_values … AsN_mass_values).
  5. All formula-unit masses are positive. The master theorem holds B-balance, Noble closure and the recipes together (recipe_mass_positive, periodic_weight_reduction_master).

-- ============================================================
-- THE B-BALANCE STOICHIOMETRY LAW
-- ============================================================
--
-- For elements e1 (bond valence B1) and e2 (bond valence B2):
-- The stoichiometric ratio n1:n2 satisfies n1 × B1 = n2 × B2
-- where n1 = B2/gcd(B1,B2) and n2 = B1/gcd(B1,B2)
--
-- This gives B_out = 0 (Noble condition) for the formula unit.
-- The production recipe follows: mass_i = n_i × MW_i (g/FU)

-- [T1] B-BALANCE LAW — core statement
-- n1 × B1 = n2 × B2 is the Noble stoichiometry condition
theorem b_balance_law (B1 B2 : ℕ) (hB1 : 0 < B1) (hB2 : 0 < B2) :
    let g := Nat.gcd B1 B2
    let n1 := B2 / g
    let n2 := B1 / g
    n1 * B1 = n2 * B2 := by
  show B2 / Nat.gcd B1 B2 * B1 = B1 / Nat.gcd B1 B2 * B2
  have hg : 0 < Nat.gcd B1 B2 := Nat.gcd_pos_of_pos_left B2 hB1
  obtain ⟨a, ha⟩ := Nat.gcd_dvd_left B1 B2
  obtain ⟨b, hb⟩ := Nat.gcd_dvd_right B1 B2
  set g := Nat.gcd B1 B2 with hg_def
  -- B1 = g·a and B2 = g·b, so both sides equal a·b·g
  rw [ha, hb, Nat.mul_div_cancel_left a hg, Nat.mul_div_cancel_left b hg]
  ring

-- [T2] RECIPE MASS — formula unit mass is positive
theorem recipe_mass_positive (n : ℕ) (MW : ℝ) (hn : 0 < n) (hMW : 0 < MW) :
    0 < (n : ℝ) * MW := by
  exact mul_pos (Nat.cast_pos.mpr hn) hMW

-- Two-sided residual: each side of the formula unit acts as one beam
-- carrying its total Behavior x = n1·B1, y = n2·B2; k = min(x, y).
noncomputable def side_residual (x y : ℝ) : ℝ := max 0 (x + y - 2 * min x y)

-- [T3] THE RESIDUAL IS |x − y|; NOBLE ⇔ B-BALANCE
theorem side_residual_abs (x y : ℝ) : side_residual x y = |x - y| := by
  unfold side_residual
  rcases le_total x y with h | h
  · rw [min_eq_left h, abs_of_nonpos (show x - y ≤ 0 by linarith),
        max_eq_right (show (0:ℝ) ≤ x + y - 2 * x by linarith)]
    ring
  · rw [min_eq_right h, abs_of_nonneg (show 0 ≤ x - y by linarith),
        max_eq_right (show (0:ℝ) ≤ x + y - 2 * y by linarith)]
    ring

theorem noble_iff_b_balance (x y : ℝ) : side_residual x y = 0 ↔ x = y := by
  rw [side_residual_abs, abs_eq_zero, sub_eq_zero]

-- [T4] A B-balanced formula unit closes Noble
theorem balanced_unit_noble (n1 B1 n2 B2 : ℕ) (h : n1 * B1 = n2 * B2) :
    side_residual ((n1 * B1 : ℕ) : ℝ) ((n2 * B2 : ℕ) : ℝ) = 0 :=
  (noble_iff_b_balance _ _).2 (by rw [h])
