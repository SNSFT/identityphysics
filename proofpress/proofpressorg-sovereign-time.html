Abstract

Sovereign Time uses the anchor Ω₀ = 1.36899099984016 GHz as a timing reference and cross-validates it against five published constants that do not change on human timescales: the fine-structure constant, whose inverse 1/α = TL × 1001 matches every published CODATA 2018 digit, and four atomic clock frequencies, Cs-133 (9 192 631 770 Hz, the SI second), Sr-87 (429 228 004 229 873 Hz), H-1 (1 420 405 751.768 Hz) and Al-27⁺ (1 121 015 393 207 857 Hz). Because every frequency is fixed, so is every clock's ratio to the anchor: Cs/Ω₀ ≈ 6.7148957, Sr/Ω₀ ≈ 313 536.03, H/Ω₀ ≈ 1.0375567 and Al/Ω₀ ≈ 818 862.50, each proved to the stated digits. Over any interval the cycles of a clock equal its fixed ratio times the anchor cycles, so one running reference recovers every other clock's count; ratios reconstruct one clock from another and compose. No clock has to run alongside another: the published values are called, locked and, if ever revised, updated by hand. Drift appears in the ratio: a reference running fast by a fraction δ reads (1 + δ) times its locked ratio against any honest reference and agrees with it exactly when δ = 0. With five anchors of which at least three are honest, an anchor is honest exactly when at least two others agree with it, so any two anchors can fail without loss. Each substrate is read as one axis of a stable identity, and its placement is recorded from its own reduction: Cs-133, with Behavior the hyperfine frequency and Pattern its 78 neutrons, at τ/TL ≈ 0.861, and H-1 at τ/TL ≈ 0.464, both Locked below the IVA band, with Sr-87 and Al-27⁺ Noble.

What This Article Proves

  1. The fixed ratios to the anchor: Cs 6.7148957, Sr 313 536.03, H 1.0375567, Al 818 862.50 (ratio_Cs, ratio_Sr, ratio_H, ratio_Al).
  2. One reference gives every clock's count; ratios reconstruct and compose; drift reads as (1 + δ) on the ratio and is caught exactly; with at least three of five anchors honest, an anchor is honest exactly when two others agree with it (cycles_from_anchor, reconstruct, ratios_compose, drift_shows_in_ratio, drift_detected, three_of_five).
  3. Placements and the coupling anchor: Cs-133 and H-1 Locked below the IVA band; TL × 1001 matches every published CODATA digit of 1/α. The master theorem holds the ratios, the cycle rule, drift detection, three-of-five and the α anchor together (cs_h_locked, alpha_anchor, sovereign_time_master).

theorem cycles_from_anchor (f t : ℝ) :
    f / SOVEREIGN_ANCHOR * (SOVEREIGN_ANCHOR * t) = f * t := by
  have hS : SOVEREIGN_ANCHOR ≠ 0 := by unfold SOVEREIGN_ANCHOR; norm_num

-- [T6] Any one live reference X gives any other clock Y through

theorem reconstruct (fX fY : ℝ) (hX : fX ≠ 0) : fY / fX * fX = fY :=
  div_mul_cancel₀ fY hX

-- [T7] Ratios compose: (X/Y)·(Y/Z) = X/Z
theorem ratios_compose (fX fY fZ : ℝ) (hY : fY ≠ 0) :
    fX / fY * (fY / fZ) = fX / fZ := by
  rw [div_mul_div_comm, mul_comm fY fZ, mul_div_mul_right fX fZ hY]

-- [T8] A reference running fast by δ reads (1 + δ) times its locked
-- ratio against an honest reference
theorem drift_shows_in_ratio (f g δ : ℝ) :
    f * (1 + δ) / g = f / g * (1 + δ) := by
  ring

-- [T9] It agrees with the locked ratio exactly when δ = 0
theorem drift_detected (f g δ : ℝ) (hf : f ≠ 0) (hg : g ≠ 0) :
    f * (1 + δ) / g = f / g ↔ δ = 0 := by
  constructor
  · intro h
    have hfg : f / g ≠ 0 := div_ne_zero hf hg
    have h2 : f / g * δ = f / g * 0 := by
      rw [mul_zero]; linear_combination h
    exact mul_left_cancel₀ hfg h2
  · intro hδ; rw [hδ]; ring

-- [T10] Three of five: anchors i have drifts δ i, and at least three
-- are honest (δ = 0). An anchor is honest exactly when at least two
-- other anchors agree with it.
open Classical in
theorem three_of_five (δ : Fin 5 → ℝ)
    (hh : 3 ≤ (Finset.univ.filter (fun j => δ j = 0)).card) (i : Fin 5) :
    2 ≤ (Finset.univ.filter (fun j => j ≠ i ∧ δ j = δ i)).card ↔ δ i = 0 := by
  constructor
  · intro h
    by_contra hi
    have hsub : Finset.univ.filter (fun j => j ≠ i ∧ δ j = δ i) ⊆
        (Finset.univ.filter (fun j => δ j = δ i)).erase i := by
      intro j hj
      simp only [Finset.mem_filter, Finset.mem_univ, true_and] at hj
      simp only [Finset.mem_erase, Finset.mem_filter, Finset.mem_univ, true_and]
      exact hj
    have hi_mem : i ∈ Finset.univ.filter (fun j => δ j = δ i) := by simp
    have hdisj : Disjoint (Finset.univ.filter (fun j => δ j = δ i))
        (Finset.univ.filter (fun j => δ j = 0)) := by
      rw [Finset.disjoint_filter]
      intro j _ h1 h2
      exact hi (h1.symm.trans h2)
    have hunion := Finset.card_union_of_disjoint hdisj
    have huniv := Finset.card_le_univ
      (Finset.univ.filter (fun j => δ j = δ i) ∪ Finset.univ.filter (fun j => δ j = 0))
    rw [Fintype.card_fin] at huniv
    have hcard := Finset.card_le_card hsub
    rw [Finset.card_erase_of_mem hi_mem] at hcard
    omega
  · intro hi
    have hsub : (Finset.univ.filter (fun j => δ j = 0)).erase i ⊆
        Finset.univ.filter (fun j => j ≠ i ∧ δ j = δ i) := by
      intro j hj
      simp only [Finset.mem_erase, Finset.mem_filter, Finset.mem_univ, true_and] at hj
      simp only [Finset.mem_filter, Finset.mem_univ, true_and]
      exact ⟨hj.1, by rw [hj.2, hi]⟩
    have hi_mem : i ∈ Finset.univ.filter (fun j => δ j = 0) := by simp [hi]
    have hcard := Finset.card_le_card hsub
    rw [Finset.card_erase_of_mem hi_mem] at hcard
    omega
